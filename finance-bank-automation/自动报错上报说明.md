# 自动报错上报说明

网关目录：`C:\Users\30112\Desktop\网关`

现在制单项目可以通过网关把运行结果交给 Codex CLI 做精简说明，再由网关把结果发回飞书。Codex CLI 只负责说明状态、关键原因和建议下一步，不自动修改文件、不重跑流程、不启动银行客户端；真正修复或重跑必须等用户明确授权。

## 工作方式

1. 银行启动器调用 `C:\Users\30112\Desktop\网关\scripts\run_and_report.py`。
2. 该脚本正常运行原来的制单命令，并把输出写入 `C:\Users\30112\Desktop\网关\data\reports`。
3. 如果原命令返回非 0，脚本调用 `scripts\report_to_codex.py` 上报到 `http://127.0.0.1:3000/agent/report`。
4. 网关找到最近的飞书会话，把错误、项目路径和日志片段交给 Codex CLI。
5. Codex 只做 3-5 行精简通知，按财务同事能直接理解的业务口径表达；不带本机路径、文件名、脚本名、任务 ID 等技术细节。自动化结果上报会单独新发最终消息，不只编辑进度消息。

## 可用启动器

- M3 总调度：`C:\Users\30112\Desktop\M3直供合同付款数据获取\run_auto_extract_dispatch_带Codex上报.bat`
- 招行：`招行\招行制单\run_zhidan_带Codex上报.bat`
- 招行批量测试：`招行\招行制单\run_batch_from_screenshots_带Codex上报.bat`
- 招行 M3 最新 30 条测试自动化：`招行\招行制单\run_m3_latest30_带Codex上报.bat`
- 兴业：`兴业\兴业制单\run_单笔转账_带Codex上报.bat`
- 兴业快速制单：`兴业\兴业制单\run_快速制单_带Codex上报.bat`
- 兴业批量只填单：`兴业\兴业制单\run_批量只填单截图关闭_带Codex上报.bat`
- 农业银行：`农业\农业银行\run_abc_batch_local_带Codex上报.bat`
- 中国银行：`中行\中国银行\启动_带Codex上报.bat`
- 中国银行批量测试：`中行\中国银行\batch_run_screenshots_带Codex上报.bat`
- 来参缘调拨定时任务：`来参缘调拨\run_laicanyuan_transfer_scheduled.ps1`
  - 与普通 `*_带Codex上报.bat` 不同，它是 Windows 计划任务入口；每轮 10:00 / 16:00 跑完后，成功、锁忙跳过、失败都会主动调用 `report_to_codex.py` 发一条业务摘要。
  - 定时入口会显式使用 `--ignore-disabled-flag`，即使网关 `data\reporting_disabled.flag` 暂停了普通自动化上报，也仍会发送这条定时结果，避免无人值守任务静默无反馈。
  - 上报失败只写入 `来参缘调拨\runtime\scheduler\scheduled_*.log`，不改变 runner 的退出码，不自动重试。

原来的启动器没有删除；如果不想自动上报，继续用原来的启动器即可。正常无人值守全流程从 M3 总调度启动：先获取 M3 付款数据，再按付款银行分流到对应银行制单，并在有效轮次结束后通过飞书发一条业务摘要。`run_m3_latest30_带Codex上报.bat` 只是招行最新 30 条测试复盘入口，没有 `pause`，可以由程序或 Windows 计划任务直接调用；它会把 M3 抽取/预检异常和招行测试制单失败都作为非 0 退出码交给网关。

M3 上报图片必须来自本轮：调用方显式传入的 M3 列表/详情/经办截图，或本轮日志里明确写出的失败现场截图。网关不再在没有本轮图片时自动翻找历史 latest 截图，避免 OA/M3 打不开时把上一轮付款信息误发到飞书。

招行支行填写有一个额外的主动提醒：如果完整支行名在“支行名称/联行号”下拉框里没有精确项，但程序选择了同银行同区县/市/省的唯一上级网点候选，必须先通过网关发一条飞书提醒；网关忙或冲突时会短暂重试，最终仍失败则本轮终止，不点击经办。真实制单模式下，这条提醒还必须随飞书发送 M3 合同付款列表截图和付款详情截图；缺任一截图则终止，不点击经办。

农行通过 M3 路由启动时，制单子流程失败会先关闭农行页面/脚本、执行 USBHub all-off，并自动重跑一次；第二次仍失败时才进入网关/最终通知路径，避免临时登录页、K 宝弹窗或浏览器状态波动造成重复误报。

## 注意

- 飞书网关必须正在运行。
- 你需要先在飞书里和机器人发过消息，网关才能知道把报告发到哪个会话。
- 上报脚本会对常见密码、PIN、Token 字段做基础脱敏，但银行日志里仍不要主动打印凭证。
- 上报不是自动修复开关；收到上报后，Codex CLI 不应改文件或重跑银行流程。
