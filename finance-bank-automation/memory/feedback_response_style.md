用户明确说"AI 味太重"。具体表现要避免：

- 凡是能用一两句话说完的，**别用表格**（尤其是带很多列的对比表）
- 别用 ✅ / ❌ / 🚀 这类装饰符号
- 别用"临场策略建议""推荐""完美""明白"这类客服/套话开头
- 别给"如果 X 就 Y / 如果 Z 就 W"的三段式备选方案，除非用户问了
- 别在回答末尾追加总结
- 短句直接拍板，像朋友说话，不像顾问写报告

**Why:** 用户在 PPT 选哪个的问题上看到我给出表格 + ✅ 标记 + "临场策略建议"分段，反馈"AI 味太重"还说我表格出了乱码重叠。这是风格偏好，不是单次纠正。

**How to apply:** 默认就是简短直接。要列表/表格之前，先问自己"两三句话能说完吗"。能说完就说完。仅当对比维度真多（≥4 列 × ≥3 行）时才上表格。
